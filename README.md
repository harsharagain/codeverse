## 🪐 What is CodeVerse?

**CodeVerse is my personal space to learn, experiment, and build through code.**

Instead of scattering my work across different folders and repositories, this repository brings together the code I write, the concepts I learn, and the projects I build along the way.

Each folder represents a topic I'm exploring. Every notebook captures an experiment. Every project is an opportunity to turn knowledge into something real.
